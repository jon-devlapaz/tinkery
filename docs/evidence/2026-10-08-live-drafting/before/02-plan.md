## What we should investigate / proposed

Investigate how to connect decisions to related work so people can find why each choice was made.

## Proposed outcome

A proposed decision-and-work graph that helps people trace each work item to the decisions behind it.

## Possible approaches / not accepted

### Use a simple linked record system / candidate only

Benefit: Quick to build and easy to change while learning what links matter.

Cost: May become hard to navigate as records grow.

Undo cost / provisional: Low; records and links can be migrated.

### Build a visual graph interface / candidate only

Benefit: Makes relationships visible and may help users explore context.

Cost: Takes more work and may not solve the underlying record-keeping problem.

Undo cost / provisional: Medium; the data may remain useful, but the interface work may be discarded.

### Extend an existing work-tracking tool / candidate only

Benefit: Can connect decisions to work where people already work.

Cost: The tool may limit the types of links and explanations supported.

Undo cost / provisional: Unknown; it depends on the tool and export options.
